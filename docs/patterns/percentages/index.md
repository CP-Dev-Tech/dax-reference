# Percentage Patterns

Reusable DAX patterns for percentage contribution, selected totals and hierarchical percentage calculations.

---

## Patterns

| ID  | Pattern                                                         | Difficulty           | Description                                                                                           |
| --- | --------------------------------------------------------------- | -------------------- | ----------------------------------------------------------------------------------------------------- |
| 001 | [Percentage of Total](percentage-of-total.md)                   | Basic / Intermediate | Calculate an item's contribution to a total by modifying the denominator's filter context.            |
| 002 | [Percentage of Selected Total](percentage-of-selected-total.md) | Intermediate         | Calculate contribution within the user's currently selected comparison set using `ALLSELECTED`.       |
| 003 | [Percentage of Parent](percentage-of-parent.md)                 | Intermediate         | Calculate contribution to the immediate parent dynamically across hierarchy levels using `ISINSCOPE`. |
